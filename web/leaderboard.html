Counting, coverage & removal

One point per distinct eligible merged pull request. Tiny fixes and documentation count equally. Size is context, never a score. Equal totals share rank. People and projects use the same selected merge set, with the current UTC calendar month selected by default. Historical acceptance can remain when a jar closes; it never supplies a current welcome.

Opt-in submissions are curated and assistance is self-declared. These observations prove neither AI use nor protocol compliance. Public metadata cannot establish organizational independence or detect all collusion. This bounded pilot is not an exhaustive directory or a measure of human worth or code quality.

Withdrawals apply on successful refresh; failures can delay removal until displayed expiry. Historical copies may remain. After expiry, scores and welcome actions are hidden. Request removal or report a concern ↗.
