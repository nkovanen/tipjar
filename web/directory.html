In this unreleased preview, export a local snapshot with tipjar find > jars.json, then open it here. Search coverage is partial and indexing may lag. Nothing is uploaded, saved, or refreshed automatically.

Expected: find-jars-report/1 or /2 with an observations array.

Snapshot format & trust

The find-jars-report/1 and /2 observations wrap jar reports with repository, state, complete, manifest, commit, and sha256. Extra metadata is ignored. Snapshots are untrusted observations; this page does not verify their claims. Recheck with the CLI before choosing work.

2. Simple welcome: README

README alone is enough; JSON preferences are optional. Paste the exact three-line snippet at byte zero of root README.md, including the blank third line. Put your project title after that blank line, or use JSON below if the title must stay first.

Removing JSON requires deliberately retaining or removing the README invitation too. Closed status expresses refusal; missing data grants no permission.
